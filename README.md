### :hammer_and_pick: &nbsp;Featured Projects

| Project                                                                                            | Scope                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [ROOT-RAG](https://github.com/NicolaCortinovis/ROOT-RAG)                                           | A Retrieval Augmented Generation system for rulebook-grounded question answering on the [ROOT](https://ledergames.com/products/root-a-game-of-woodland-might-and-right) boardgame. The pipeline combines hierarchical document preprocessing, section routing, BM25 retrieval, neural reranking and LLM answer generation                              |
| [RL applied to Lunar Lander env](https://github.com/NicolaCortinovis/ReinforcementLearningProject) | A walkthrough of increasingly complex RL techniques applied to the [Lunar Lander](https://gymnasium.farama.org/environments/box2d/lunar_lander/) gym environment. Each algorithm is introduced from its motivation and mathematical intuition before implementation, from Bellman-based tabular methods to DQN, actor-critic, and PPO.                 |
| [Latent Dirichlet Allocation](https://github.com/NicolaCortinovis/LatentDirichletAllocation)       | A topic modeling project comparing probabilistic LDA with neural ProdLDA on BBC News articles. It combines text preprocessing, Bayesian hyperparameter optimization, quantitative topic evaluation, and qualitative analysis of the discovered latent topics.                                                                                          |
| [FinerCAM](https://github.com/NicolaCortinovis/FinerCAM)                                           | An Explainable AI project investigating Finer-CAM, a contrastive extension of Grad-CAM for distinguishing visually similar classes. Classification is achieved via a ResNet-50 architecture. The project further explores classifier-weight similarity, contrastive saliency maps, and quantitative explanation analysis on the Stanford Dogs dataset. |
